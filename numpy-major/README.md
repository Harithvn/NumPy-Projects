🧮 NumPy Mathematical Calculator

A simple Python-based NumPy calculator that allows users to perform a variety of mathematical, statistical, and array manipulation operations using NumPy.
This project is ideal for beginners who want to understand NumPy operations, array handling, and basic Python exception handling.

🚀 Features
1️⃣ Arithmetic Operations

Perform element-wise operations on two NumPy arrays:

Addition (+)
Subtraction (-)
Multiplication (*)
Division (/)
Floor Division (//)
Modulus (%)
Exponential (**)

2️⃣ Statistical Operations

Combine two arrays and compute:
Mean, Median, Standard Deviation, Variance
Minimum, Maximum, Sum, Product
Shape, Size, and Data Type

3️⃣ Array Manipulation

Perform advanced array operations:

Concatenation

Reshaping (1D, 2D, or 3D arrays)

Sorting and Reverse Sorting

Finding Unique Elements

Accessing First & Last Elements

Filtering elements based on mean value

🧰 Requirements

Before running this project, make sure you have the following installed:

Python 3.x

NumPy library

Install NumPy using pip:

pip install numpy

▶️ How to Run

Clone this repository

git clone https://github.com/yourusername/numpy-mathematical-calculator.git


Navigate into the project directory

cd numpy-mathematical-calculator


Run the Python script

python numpy_calculator.py


Follow the on-screen instructions

Enter two arrays separated by spaces.

Choose an operation (Arithmetic, Statistical, or Array Manipulation).

💡 Example Usage

Input:

Enter the ele with space: 1 2 3
Enter the ele with space: 4 5 6


Select Operation:

1. Arithmetic Operations
2. Statistical Operations
3. Array Manipulation
4. Exit


Output (Arithmetic Example):

addition       : [5 7 9]
subtraction    : [-3 -3 -3]
multiplication : [ 4 10 18]
division       : [0.25 0.4 0.5]
floor division : [0 0 0]
modulus division: [1 2 3]
exponential     : [1 32 729]
